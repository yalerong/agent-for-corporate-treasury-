三态规律库

规律重算只产生 candidate；人工批准（approved）才进计算—— strict 门控默认开，approved=0 时回退置信度口径并明示"过渡模式"；refuted 只能人为， 重算永不复活（防重提）。审批走非交互 CLI 或本地审批台 UI，写盘前自动备份。

核验环 + 自动降级

每条规律用最近付款回测：预期日 ±3 天找付款、 金额 ±40% 内为 hit，缺失或出带为 violated，数据边缘为 uncertain。违反进人审清单； 连续 2 次 hit_rate<0.5 的 approved 自动降级回 candidate——自动路径永不置 refuted。

LLM 三重闸

LLM 只见聚合 profile（周统计量/日历直方图/Top收款方聚合额）， 绝不见单笔流水；产出必须带可复算 checks——① schema 校验 ② 数字与 profile 复算偏差>5% 拒收 ③ pattern_id 去重。通过者只进候选池，走同一条人工审批通道；无 API Key 全流程照常。

安全红线

付款执行永远不给 Agent 工具——安全靠工具不存在，不靠 Prompt。 调拨建议 preview-only；自主权滑块按金额/关键词分档标注人审档，只标注不拦截； 真实数据全部 gitignore，仓库只含代码与合成示例。
